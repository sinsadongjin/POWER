# POWER

출퇴근 달력 앱 배포용 공개 저장소. 최신 APK 와 버전 정보만 둡니다.

## [📥 WorkClock.apk 받기 (최신)](https://github.com/sinsadongjin/POWER/raw/main/WorkClock.apk)

1. 위 링크를 눌러 받기 (크롬)
2. 갤럭시는 설치 전에 **설정 → 보안 및 개인정보 보호 → 자동 차단** 끄기 (설치 뒤 다시 켜도 됨)
3. 받은 WorkClock.apk 열기 → 설치(업데이트). 기록은 그대로 남아요.

- `version.json`: 앱이 새 버전을 확인할 때 읽는 버전 번호
